# LyricMotion

LyricMotion is a premium music web experience built with Next.js, TypeScript, Tailwind CSS, and a local-first media workflow.

## Features
- Immersive dashboard
- Audio upload with drag and drop
- Library and playback UI
- Visualizer and lyric experience
- Profile, favorites, and listening history
- Search and recommendations
- Theme selection

## Getting Started

### Install dependencies
```bash
npm install
```

### Run locally
```bash
npm run dev
```

Open http://localhost:3000
